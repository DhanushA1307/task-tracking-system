Powershell:

Frontend:
cd frontend; npm.cmd run dev

Backend (Option 1 - Helper Script):
.\start_backend.ps1

Backend (Option 2 - Clean One-Liner):
Stop-Process -Name "python*" -Force -ErrorAction SilentlyContinue; cd backend; $env:PYTHONPATH='.'; & "venv\Scripts\python.exe" -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

# Check current telemetry and next scheduled run:
& "backend\venv\Scripts\python.exe" -m app.services.notification_cleanup_service --status

# Run cleanup manually:
& "backend\venv\Scripts\python.exe" -m app.services.notification_cleanup_service --run

# Enable or disable the service:
& "backend\venv\Scripts\python.exe" -m app.services.notification_cleanup_service --enable
& "backend\venv\Scripts\python.exe" -m app.services.notification_cleanup_service --disable
